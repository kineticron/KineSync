## Actual source and implementation

- `ExpoLyrics/components/lyrics/native/native-skia-voice.tsx:213-226,251-252`
  defines foreground translation size, leading, requested weight, .3 opacity,
  width subtraction, inset and margin. Spicy uses14/18 logical points times
  source fontScale,500, x2/width-4/margin4. AMLL uses max(10,fontSize*.5),
  1.5 leading,700 and no extra margin/inset. `src/auxiliary.rs` ports these
  policies and uses the same registered existing SF asset ownership. Actual
  selected faces/requested attributes are included in layout receipts; this
  is not proof of identical native Skia/Parley metrics.
- `native-lyrics-model.ts:66` (`buildNativeVoice`) already carries translation.
  `rust-lyrics-preparation.ts` now passes the actual selected line text through
  that helper; the Rust view explicitly subscribes to the existing store setting.
  A toggle/content update sends one generation/immutable packet, not frame ticks.
- Schema/ABI6 carries optional `paint.translation`; all C/JS/Swift guards and
  tests agree on6. KRMetrics remains152 bytes; no C struct layout change.
  Rust rejects oversized subtitle text and missing glyphs. No new font/dependency,
  restricted OS-font copy or native resource/package policy change.
- `src/scene.rs` shapes a subtitle once when its owning plain row becomes visible,
  caches its static paragraph scene and actual faces, and includes its height in
  row flow, prefix/scroll and the single shared protected envelope. Static text
  is not an animated glyph-picture cache. Translation identity participates in
  the complete serialized track/cache key; hidden/visible keys differ and owner
  timing still resets on generation/seek/resize. Cached row eviction drops its
  subtitle glyph ownership too.
- `src/timed_scene.rs` appends that cached paragraph with source outer opacity
  and AMLL whole-voice scale. It does not inherit timed word bright/dark alpha.
  No per-frame shape, scene-recording allocation or readback; no new GPU pass/filter/target,
  per-line blur, GPU wait, queue capacity, epsilon gate or phone optimization.
  Full-res sharp/half-res shared blur, native clock, two-frame ownership and
  clipping remain structurally unchanged. Existing ownership/clock tests pass.
- `app/(tabs)/index.tsx:1833` keeps attribution outside the native lyric surface
  and shared blur, using the existing chrome/controls positioning. Existing
  `lyrics-attribution.tsx` gains optional Rust-only `allCredits`, exposing exact
  non-Spicy provider/profile metadata and credit-only data. Existing modal,
  profile rendering and Linking callbacks are reused; provider HTTPS URL gets
  the same real callback guard. Non-Rust eligibility stays unchanged. This is
  the sharp global overlay, not native end-footer/timestamp-seek parity.
